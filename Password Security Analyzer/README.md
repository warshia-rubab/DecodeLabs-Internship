# 📖 Introduction

In the modern digital landscape, weak passwords are the leading cause of unauthorized access and data breaches. 
This project, **Password Security Analyzer**, serves as the **defensive phase**. It is designed to demonstrate core security logic, data validation, and string handling by evaluating the strength of user-provided passwords in real-time.

<br>
By combining **Client-side logic** (Entropy calculation, Pattern recognition) with a **Server-side backend** (Node.js & Express) and **Real-Time API integration** (Have I Been Pwned). This tool provides a comprehensive, 
professional-grade approach to password security. 
The application also features an advanced password generator, full backend logging, and a dynamic dual-theme interface to offer a complete user experience.

# ✨ Key Features

- 🧮 **Entropy & Complexity Analysis:** Calculates length, character diversity, and entropy to generate a score from 0-100.
- 🚨 **Real-Time Breach Checking:** Uses the **"Have I Been Pwned"** API to instantly flag passwords found in real-world breaches (SHA-1 hashed).
- 🎯 **Dynamic Recommendations:** Gives specific advice like *"You forgot to add a Number (0-9)!"*.
- 🎲 **Advanced Password Generator:** Custom length slider and character toggles.
- 🌗 **Dual Theme (Instant Switch):** Dark/Light modes with smooth background, particle, and lock animations.
- 📋 **Full Backend Logging:** Logs every user action to CMD and a persistent `.txt` file.
- ⚡ **One-Click Launch:** Custom `start_project.bat` file.

# 🚀 How to Run Locally

1. Install
  
    [Node.js](https://nodejs.org/).
   
4. Open terminal in project folder:
   
   ```bash
   npm install express cors
   ```

5. Double-click start_project.bat  OR run:
   
   ```bash
    node server.js
   ```
6. Open browser: 

    http://localhost:3000
